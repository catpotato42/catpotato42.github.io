# catpotato42.github.io

Personal portfolio site for Simon Harrington. Astro, static output, no client JS.

## Development

```sh
npm install
npm run dev      # local dev server
npm run build    # static build to dist/
npm run preview  # serve the build
```

## Deploys

GitHub Actions builds and publishes from `main` on push (`.github/workflows/deploy.yml`).
